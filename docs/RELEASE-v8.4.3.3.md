# v8.4.3.3 - 大表格安全拆页版

## 底座

严格基于 8.4.3.2「行级连续切页根治版」。答案图片行模型、重叠保护开关、手动切线、题目结构、分段页码等逻辑均保持原样。

## 本版只解决一个新问题

英语等试卷中存在大型 HTML 表格。8.4.3.2 将整个 `<table>` 视为不可拆元素；当当前页剩余空间放不下整张表时，会把整张表推到下一页，从而在上一页留下很大空白。

8.4.3.3 改为：

1. 当大表格跨出当前 A4 页底时，读取每个真实 `<tr>` 的实际位置。
2. 找到当前页能够完整容纳的最后一行。
3. 从该位置向上检查最近的安全行边界。
4. 如果某条边界被 `rowspan` 跨行合并单元格穿过，则禁止在这里拆分。
5. 找到安全边界后，将同一张表拆成前后两段，前段留在本页，后段进入下一页。
6. `colspan` 不影响纵向拆分，因此正常保留。
7. `caption` 只保留在第一段，续页不会凭空重复表标题。
8. 表格前后的原题内容分别保留在对应页，不删除、不重复题干。
9. 如果整张表没有任何安全的行边界（例如单个超高行、`rowspan` 跨越整表），仍退回 8.4.3.2 的“整表换页”方式，优先保证原卷结构不损坏。

## 不会改变的内容

- 答案长图文字行模型分页
- 答案切线智能吸附
- 切线附近文字重叠保护开关
- 手动 Y / ±1 / ±10 / 拖动 / 复位
- 原题号
- 题目/答案分段页码
- 14px 标准精排
- 普通页/组卷中心结构识别
- “添加题型下试题”等编辑文字清洗

## 英语 PDF 实例

第 4 页在第 33 题后仍有明显可用空间，而第 5 页从完整的 `SUNSHINE SCHOOL WEEKLY / A Taste of Lychees` 大表格开始。这与“整张 table 不允许拆分”完全吻合。本版专门处理这一类空白。

## 测试建议

优先重新打印同一份广州中考英语卷，重点看原第 4/5 页交界。理想结果是大表格可以在安全的表格行边界跨页，而不再把整张表全部推到下一页。

如果网页实际把整块复杂版式做成一个单独的超高 `<tr>`，或一个 `rowspan` 覆盖了几乎整张表，则为了不破坏合并单元格，本版仍可能整块换页。这种情况需要页面保存后的 HTML 才能继续做“单元格内部安全分页”。
