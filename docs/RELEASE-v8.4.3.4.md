# v8.4.3.4 - 原题着重号恢复版

## 本版重点

本版严格基于 v8.4.3.3，只增加组卷网原题 `<dot>` 标签的文字下方着重号样式恢复。

- 在 A4 打印预览 CSS 中恢复 `text-emphasis` 着重号规则，并增加 `-webkit-` 前缀兼容 Chromium / Chrome / Edge。
- 在独立 HTML / Word 共用的导出 HTML CSS 中加入相同 `<dot>` 样式。
- 不向正文插入 `·` 字符，也不使用伪元素人工画点，避免改变原题文字内容和横向宽度。

## 保持不变的稳定逻辑

本版没有改动以下核心能力：

- 答案长图行级切页；
- 切线附近文字重叠保护；
- 手动切线；
- HTML 大表格安全拆页；
- 原题号；
- 题目/答案分段页码；
- 其他 v8.4.3.3 已稳定的分页逻辑。

## 验证

- 主 Userscript：`node --check` 通过；
- 预览 iframe 脚本：`node --check` 通过；
- 自动回归检查：`ALL_PASS`；
- 分页核心函数与 v8.4.3.3 哈希一致。

开发环境中的 headless Chromium 仍存在 DBus / 进程退出超时问题，因此浏览器端到端截图测试未计入通过项；最终显示仍建议在真实组卷网页面预览中确认。
