# 组卷网试卷打印工作台

用于 `zujuan.xkw.com` 的 Tampermonkey 用户脚本，目标是把组卷网页面整理成更适合 A4 打印、保存 PDF 和导出的试卷版式。

> 当前稳定版：**v8.4.3.4 - 原题着重号恢复版**  
> 稳定主线以 **8.4.3** 为基础继续维护；实验性的 8.5.x 不作为当前稳定基线。

## 主要功能

- 支持普通试卷详情页和组卷中心。
- 支持四种打印内容：仅试题、试题与答案、答案移至末尾、仅答案。
- 保留网站原卷题号，不在题目正文前重复生成题号。
- 清洗网页编辑控件文字，例如“添加题型下试题”。
- A4 独立分页预览，可调整字体、字号、行距、标题字号、页边距、题间距等。
- 默认题目/答案分段页码，答案部分重新从 `1 / N` 开始计数，页脚只显示数字。
- 图片型答案使用原图虚拟视窗分页，不重新编码答案图片。
- 答案长图使用文字行模型选择安全切线，减少切字和为找白线产生的大块空白。
- “切线附近文字重叠保护”可单独开启/关闭。
- 支持答案切线手动微调：Y 坐标、±1、±10、拖动、吸附、复位。
- HTML 大表格优先在真实 `<tr>` 边界分页，并避开 `rowspan` 穿越的危险边界。
- **v8.4.3.4 恢复原题 `<dot>` 标签的文字下方着重号**，打印预览和独立 HTML 导出均带入对应 `text-emphasis` 样式。
- 支持 Word（DOCX）、独立 HTML、结构化 JSON 导出。
- 浮动打印按钮可拖动，双击恢复默认位置。
- 支持彩色打印或黑白增强。

## 安装

### 推荐方式：Tampermonkey 手动安装

1. 浏览器安装 Tampermonkey。
2. 点击 **[组卷网试卷打印工作台 v8.4.3.4](./组卷网试卷打印工作台-8.4.3.4-原题着重号恢复版.user.js)**。
3. 在 GitHub 文件页面点击右上角 **Raw**。
4. `Ctrl + A` 全选脚本内容，再 `Ctrl + C` 复制。
5. 打开 Tampermonkey → **添加新脚本**。
6. 删除编辑器里的默认内容，粘贴刚才复制的完整脚本。
7. 按 `Ctrl + S` 保存。
8. 打开 `https://zujuan.xkw.com/` 的试卷页面，右下角会出现“打印试卷”按钮。

> 当前稳定版：**v8.4.3.4 - 原题着重号恢复版**
>
> 某些浏览器直接打开 `.user.js` 可能提示“不支持的文件类型”，这种情况下使用上面的“复制 → 粘贴到 Tampermonkey”方式安装即可。

## 打印模式

| 模式 | 行为 |
| --- | --- |
| 仅试题 | 只打印题目 |
| 试题与答案 | 题目后直接显示对应答案 |
| 答案移至末尾 | 先打印完整试题，再打印“答案与解析” |
| 仅答案 | 只打印答案内容 |

## 分页设计

### 普通题目正文

题目正文保持 HTML 结构，分页器按实际 A4 可用高度拆分；原卷题号直接保留。

### 图片型答案

组卷网很多“答案与解析”是服务器生成的长图片。脚本会分析答案图的纵向文字行，优先把切线放在当前页能够完整容纳的最后一行之后，而不是远距离寻找“最佳白线”。目标是：

- 不把一行文字切成上下两页；
- 不为了避字向上退很多行，减少页尾大块空白；
- 复杂区域无法可靠识别时，可用重叠保护保证内容完整。

### HTML 大表格

从 v8.4.3.3 起，脚本专门处理英语等试卷中的大型表格。旧逻辑把整个 `<table>` 当成不可拆元素，只要当前页放不下整张表，就会把整表推到下一页，上一页可能留下半页空白。

现在的处理逻辑：

1. 读取表格中每个真实 `<tr>` 的实际位置；
2. 找到当前 A4 页面能够完整容纳的最后一行；
3. 检查分页边界是否被 `rowspan` 跨越；
4. 安全时在该 `<tr>` 边界拆表；
5. `colspan` 原样保留；
6. 续页不凭空重复 `caption`；
7. 没有安全行边界时回退为整表换页，优先保证原卷结构。

## 原题着重号

v8.4.3.4 修复语文试题中“加点词”在原网页可见、但进入打印预览后文字下方着重号消失的问题。

组卷网原题使用自定义 `<dot>` 标签，并由网站 CSS 通过 `text-emphasis` 绘制文字下方着重号。本版在独立预览和导出 HTML 中补回对应样式，并增加 `-webkit-` 前缀兼容 Chromium / Chrome / Edge。

本版不会向正文插入额外的 `·` 字符，也不会用伪元素人工画点，因此不会改变原题文字内容和横向宽度。

## 答案重叠保护

设置项：**切线附近文字重叠保护（防丢字）**。

- 开启：复杂/低置信度切线会让下一页重复少量上一页内容，优先保证答案完整。
- 关闭：不重复切线附近内容，但智能切线仍然工作。

## 手动切线

自动切线不满意时，可在预览中对答案图片切线执行：`-10`、`-1`、直接输入原图 Y 坐标、`+1`、`+10`、吸附、拖动和复位。

## 页码

默认采用题目/答案分段计数，例如：

- 题目：`1 / 8 ... 8 / 8`
- 答案：`1 / 6 ... 6 / 6`

页脚不额外显示“试题”“答案”文字，也可切换为整卷连续计数。

## 导出

预览顶部提供 Word、HTML、JSON 导出。部分跨域图片会通过 `GM_xmlhttpRequest` 获取；若网站资源策略变化，个别图片可能保留为网络地址。

## v8.4.3.4 本版重点

本版严格基于 v8.4.3.3，只增加 `<dot>` 着重号样式恢复。答案图片行模型、重叠保护开关、手动切线、大表格安全拆页、原题号、分段页码以及普通页/组卷中心结构识别均保持原样。

详细变更见 `docs/RELEASE-v8.4.3.4.md`，回归结果见 `docs/REGRESSION-v8.4.3.4.md`。

## 回归测试原则

项目经历过多次“修一个功能，旧问题又回来”的情况，因此当前版本采用固定回归策略：

- 主 Userscript JavaScript 语法检查；
- 预览 iframe JavaScript 语法检查；
- 历史功能固定检查；
- 分页/结构关键函数 SHA-256 冻结比对；
- 新增逻辑必须有针对性自动检查。

v8.4.3.4 的自动检查结论为 **ALL_PASS**。

## 已知限制

- 如果复杂表格本身只有一个超高 `<tr>`，或一个 `rowspan` 几乎跨完整张表，则没有安全行边界可拆，此时会保持整表换页。
- 图片型答案内部文字属于位图，CSS 无法真正改变图片里的字体和字号，只能整体缩放答案图片。
- Word 对 CSS `text-emphasis` 的支持取决于具体 Word 版本；独立 HTML 在现代浏览器中可正常表现。
- 网站 DOM、答案接口或 CSS 结构变化后，脚本可能需要更新选择器。
- 当前自动回归包含语法、函数哈希和 JavaScript 逻辑测试；开发环境中的 headless Chromium 曾因进程退出问题无法稳定完成端到端浏览器测试，因此最终 PDF 仍应进行真实页面回归。

## 问题反馈建议

遇到分页异常时，最好提供插件版本号、打印 PDF、异常页码；若是网页结构问题，再提供答案全部展开后的保存网页 HTML；若是答案图片问题，可提供对应的原始答案长图。
